# Contributing to Agent Vector Protocol

## How to Contribute

### Questions & Discussions
Open a [GitHub Discussion](https://github.com/vectorarc/avp-spec/discussions)

### Bug Reports
Open an [Issue](https://github.com/vectorarc/avp-spec/issues)

### Protocol Changes
Use the **RFC (Request for Comments) process**:

1. Copy `rfcs/0000-template.md`
2. Fill in your proposal
3. Submit Pull Request
4. Community discusses
5. Accepted or rejected

See [rfcs/README.md](rfcs/README.md)

### Documentation
Pull Requests welcome! No RFC needed.

## Code of Conduct
- Be respectful
- Focus on ideas
- Welcome newcomers
- Assume good faith
