# AVP RFC Process

## What is an RFC?

RFC = Request for Comments. Design documents for protocol changes.

## When to Write

Write RFC for:
- New features
- Breaking changes
- Behavior modifications

NOT needed for:
- Bug fixes
- Docs
- Implementation details

## Process

1. Draft → Copy template
2. Submit → Open PR
3. Discuss → Community reviews
4. Revise → Update based on feedback
5. Decision → Accepted/rejected
6. Implement → Update spec if accepted
